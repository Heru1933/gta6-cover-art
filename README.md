Vice Coast — an offline web app that turns any photo and a caption into GTA 6 poster-style cover art: multi-panel layouts, Vice City sunset and neon colour grades, bold poster lettering, and PNG export in post sizes (1080×1080, 1080×1350, 1920×1080). No Rockstar logo, artwork or fonts — all art and lettering is original, drawn in code. Photos never leave the machine.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser, load a photo (or several), pick a layout and grade, edit the caption, and export a PNG.
